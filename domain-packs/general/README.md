# General citizen reports

The default Witness form covers public services, infrastructure, environmental issues and other community
problems. Reporters can select `other` when unsure and leave unknown details blank. Witness uses neutral
incident labels for every report and does not expose domain-pack selection in the public reporting flow.

This pack deliberately defines no automatic violation rule or evidence-expiry window. Neither the food
safety four-hour rule nor the MBG physical-sample deadline applies to a general report. Evidence strength
and findings still require human validation.
